# Architecture: i18n (Multilingual Support)

## Supported Languages

| Code | Language | Native Script | Browser Locale |
|------|----------|---------------|----------------|
| `en` | English | English | `en-*` (default) |
| `hi` | Hindi | हिन्दी | `hi-*` |
| `bn` | Bengali | বাংলা | `bn-*` |
| `ta` | Tamil | தமிழ் | `ta-*` |
| `te` | Telugu | తెలుగు | `te-*` |
| `mr` | Marathi | मराठी | `mr-*` |
| `gu` | Gujarati | ગુજરાતી | `gu-*` |

---

## Implementation

### Translation Dictionary — `src/i18n/translations.ts`

A single TypeScript file exports:

- `SupportedLanguage` — Union type of all 7 language codes.
- `SUPPORTED_LANGUAGES` — Array of `LanguageMeta` objects (code, name, nativeName, flag).
- `translations` — `Record<SupportedLanguage, Record<string, string>>` — the full dictionary.

**Key naming convention:** `section.camelCaseKey`

Examples:
```ts
'nav.overview'           // "Overview" / "अवलोकन" / "সংক্ষিপ্ত বিবরণ" …
'hero.liveAirQuality'    // "Live local air quality"
'health.title'           // "Clinical Health Guidance & Precautions"
'footer.tagline'         // "Breathe Smarter. Live Better."
```

### Language Context — `src/context/LanguageContext.tsx`

Provides:

| Export | Type | Description |
|--------|------|-------------|
| `LanguageProvider` | Component | Wraps the app; must be an ancestor of any consumer |
| `useLanguage()` | Hook | Returns `{ language, setLanguage, t, languages, currentLanguage }` |

**`t(key, params?)` function:**
- Looks up `translations[language][key]`.
- Falls back to `translations.en[key]` if the key is missing in the selected language.
- Falls back to `key` itself if missing in English too (prevents blank UI).
- Supports parameter interpolation: `t('hero.aqiValue', { value: 175 })` replaces `{value}` in the string.

**Auto-detection order:**
1. `localStorage.getItem('breathe-lang')` — restore previously selected language.
2. `navigator.language` — map browser locale prefix to supported language code.
3. Default: `'en'`.

### Language Selector — `src/components/layout/LanguageSelector.tsx`

A dropdown embedded in the `Navbar`. Displays native script labels (e.g., `हिं`, `বাং`) and updates `LanguageContext` on selection.

## Adding a Translation Key

1. Add the English string to `translations.en` in `src/i18n/translations.ts`.
2. Add the translation to every other language block (`hi`, `bn`, `ta`, `te`, `mr`, `gu`).
3. Use the key in the component: `const { t } = useLanguage(); return <h1>{t('your.newKey')}</h1>`.

> **Important:** Every new key must be added to all 7 language dictionaries to prevent untranslated fallback text in production.

## AI Chat Language Sync

`BreatheAiChat` reads `currentAppLang` from `useLanguage()` and maps it to the AI response language:

```ts
const langCodeToName = { hi: 'Hindi', bn: 'Bengali', ta: 'Tamil', … }
const [language, setLanguage] = useState(() => langCodeToName[currentAppLang] || 'Auto');

useEffect(() => {
  if (langCodeToName[currentAppLang]) setLanguage(langCodeToName[currentAppLang]);
}, [currentAppLang]);
```

This means switching the UI language in the Navbar also updates the BreatheAI assistant's response language and speech synthesis voice locale.
